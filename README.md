# Personal Portfolio Website (Designed from Scratch)

A clean, responsive, and accessible personal portfolio website built 100% from scratch using semantic HTML5, modern CSS3 (Grid & Flexbox), and vanilla JavaScript. 

Developed as the final capstone project for the **Web Design for Everybody: Basics of Web Development & Coding Specialization** by the University of Michigan on Coursera.

## Grading Rubric Compliance

This project satisfies all criteria outlined in the **Portfolio Grading Rubric (100 Points Total)**:

### 1. W3C Validation (20 Points)
* Strict semantic HTML5 document structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* Zero markup syntax errors, fully closed tags, valid attributes, and complete `<head>` metadata.

### 2. Responsiveness & Viewports (20 Points)
* **Mobile Viewport (Narrow):** Uses single-column stacked elements, mobile-friendly spacing, and touch-optimized interactive controls matching the Module 2 wireframe.
* **Desktop Viewport (Wide):** Expands to a multi-column layout featuring a split hero section, a 3-column project showcase grid, and horizontal navigation.
* Engineered via CSS Grid (`repeat(auto-fit, minmax(290px, 1fr))`) and Flexbox media queries (`@media (max-width: 768px)`).

### 3. Styling & Accessibility (10 Points)
* Written from scratch with over 20 unique CSS rules (no UI frameworks or templates).
* **WAVE Accessibility:** Implemented a visible **Skip to Main Content** link, high-contrast text color combinations exceeding WCAG AA standards, explicit `<label>` tags for form elements, and focus outlines for keyboard navigation.

### 4. Effective Image & Icon Usage (10 Points)
* Visual iconography integrated into each project showcase card to provide immediate context without visual clutter.

---

## Four "Extras" Implemented (40 Points)

1. **Sticky Footer Structure:** Built using a flexbox container (`min-height: 100vh` and `flex-direction: column`) to guarantee the footer remains pinned at the bottom across varying viewport heights.
2. **Interactive Google Calendar Plugin:** Embedded public schedule iframe styled inside an aspect-ratio responsive wrapper to handle scheduling and office hours.
3. **Custom DOM Interaction (JavaScript):** Custom vanilla JS event listener on the contact form providing dynamic validation feedback and automatic form reset without page reload.
4. **Font Awesome Vector Icons:** Integrated scalable vector icons across project cards, tech stacks, and social links with explicit `aria-hidden="true"` tags to protect screen reader users.
